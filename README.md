# Смысл проекта
Я пытаюсь написать код для работы с камерами

Тут я пытаюсь перенести 2 основных модуля для работы с камерами

## Перечень, что хочу сделать
1. Все камеры должно работать одновременно.
2. Последняя подключаемая камера отвечает за обнаружения лазера.
3. Есть трансялция и запись в виде разных функци.
4. Должна быть обработка лазера для обнаружения его на кадре.

# Важные уточнения
